# 「持仓与盈亏」页：说明进「？」、提示说人话、图不留空（2026-11-18）

分支：`feat/report-page`（从 main 3b3a480 拉出，工作区在 `.claude/worktrees/report-page`）。
这是一份**事后补的设计记录**。流程同 11-16 那几轮：用户对着截图提了三条，先在 `/tmp` 的副本里把三处都
复现出来、量了数，再在隔离的工作区里改，**页面一能看就先开预览给用户**，然后才补测试、真机看各种状态、
变异自查、独立审查。用户看过预览后回的是「可以，审查后合并」；审查挑出的问题见 §6，修完才合并。

## 0. 起因

用户（2026-11-18）对着「持仓与盈亏」页的截图提的三条，原话：

1. 「"这些数字怎么算的、已知局限"——这个说明需要专门做一个下拉框吗？」
2. 「"卖出 1000 股但只有 0 股配得上买入批次，未配对的 1000 股成本未知，不计入已实现盈亏——是不是漏记了一笔买入？"、
   "持仓里的 ×××××× 不在信号池里——「信号跟踪」不会盯它们的卖出。"——这两句话啥意思？还搞得那么显眼」
3. 「仪表盘的持仓占比比例很别扭，为什么左边要空出一大块空间？」（截图里把左半栏圈了出来：「空白的，什么也没有」）

对应到他账本里的两件事：有一笔卖出，账上没有那只票的买入（开始记账之前买的）；持有的一只票没加进信号池。

**本文与测试里的例子一律用虚构的票和数**（招商银行、美的集团、贵州茅台……）。仓库是公开的，而交易记录是用户
自己的数据、不进仓库（README「你的数据在哪」）；上面引的原话里那个六位代码也隐去了。初稿把他账本里的那笔交易
与持仓市值原样抄进了例句、注释和测试夹具，推送前自查时发现，全部换掉并重写了那三个还没公开的本地提交。

## 1. 页顶的折叠区并进页名后面的「？」

那个折叠区是 11-16「减字」那一轮**有意留下的**（当时的理由：它本来就是"要看才展开"）。用户这次的反应说明
那条理由不成立：折叠着它也是页面最上面常驻的一行，而且标题许了两件事（怎么算的、已知局限），里面只有后一件。
按 11-16 定的判据——**不会变的就是解释，进最近的那个「？」**——它该进圆点。

- 内容进了页名后面的帮助圆点（`guide.JOURNAL_REPORT_INTRO`，经 `ui.PAGE_INTRO`）：这页给你看什么；
  这些数是按你记的账算的、不是券商数据；配股与要约收购要手工记；不做税务口径。
- 「浮动盈亏依赖本地行情」那一条**没有**搬过去：它已经在「仪表盘」小标题的圆点（`JOURNAL_PNL_HINT`）与
  那两列自己的列头说明里，同一屏不说第三遍。
- `guide.JOURNAL_LIMITS` 没有人用了，删了（README 自己有一份完整的）。
- **没动的**：「记账」页页顶那个同类的折叠区（这一页记什么、四种记录类型的含义）。里面是一张表，帮助圆点放不了表，
  用户也没点名；已经告诉他有这么一处，等他定。

## 2. 两句提示：看得懂、知道去哪处理、不抢眼

### 2.1 为什么看不懂

| | 原句 | 毛病 |
|---|---|---|
| 账上对不上 | 卖出 1000 股但只有 0 股配得上买入批次，未配对的 1000 股成本未知，不计入已实现盈亏——是不是漏记了一笔买入？ | **没说是哪只票**（标记里有代码，句子里没有）；「配得上」「批次」「未配对」「成本未知」全是算盈亏那一层自己的词；没说下一步做什么 |
| 不在信号池 | 持仓里的 ×××××× 不在信号池里——「信号跟踪」不会盯它们的卖出。 | 只有代码没有名称；「盯卖出」是什么、信号池是什么都没解释；它不是错，却和上一条一样是黄框 |

### 2.2 句子怎么写（`quant.journal.pnl`）

三条规矩，八种标记一并照做（不只是用户看到的那一种——它们出现在同一个地方，是同一个毛病）：

1. **先说是哪只票、哪一天**：`招商银行（600036）2026-03-12 …`；账上没有它的名称时是 `600036 2026-03-12 …`。
2. 不用本模块自己的词：说「账上在这之前没有它的买入记录」「算不出盈亏」「没有计入」。
3. 最后半句是**下一步做什么**。"为什么要跳过"（当成 0 会凭空造出一笔持仓）是写给改代码的人看的，留在注释里。

**卖出比那一刻账上有的多，分三种说**（初稿只分两种、而且把话说错了，见 §6 第 1 条）：

| 情形 | 句子 | 补救 |
|---|---|---|
| 在这之前**从没记过它的买入**（最常见：开始记账之前买的） | …卖出 1,000 股，但账上在这之前没有它的买入记录，这笔的盈亏算不出来、没有计入。 | 补记当初的买入就能算（成交日期要早于这笔卖出）。 |
| 记过买入，但**在这之前已经卖完了** | …但按账上的记录，它在这之前已经卖完了，这笔的盈亏算不出来、没有计入。 | 是不是漏记了买入，或者送股、转增没有记？补记的日期要早于这笔卖出。 |
| 记过买入，那时**手里还剩一些，但不够** | …但按账上的记录，那时手里只有 400 股，多出来的 200 股算不出盈亏、没有计入。 | 同上 |

- 后两种必须提「送股、转增没有记」：只提「漏记买入」的话，10 送 3 没记的人会照做去凭空补一笔买入——
  提示是消失了，成本却被悄悄改坏（`pnl` 模块 docstring 第 3 条说的就是这种错）。
- 三种都带「日期要早于这笔卖出」：先进先出按日期逐笔处理，补一笔日期更晚的记录配不上那笔卖出，
  账上反而多出一笔并不存在的持仓——有测试钉着这半句说的是真的。
- 股数带千分位、不用 `:g`（它把一百万写成 `1e+06`）。读不出来的行：类型认得就写中文名，日期只写日期，空着的写「空」。
  股数或成交价**填了但不是正数**的，不说「缺」；缩股正好缩到 0 的，不说「持仓不可能是负的」。

### 2.3 页面怎么摆

原设计（v0.3.0 §3）是「警告显眼、持续可见」。**"持续可见"留着，"显眼"换成"看得懂、知道去哪处理"**：

- **账上对不上的地方**：仍排在所有数字之前、仍然一直留到补齐为止——它意味着下面的数少算了一块。
  但不再是 `st.warning`：一块原生的带边框区域，左边一条一句（`theme.notice`，正文色、无底色、句首一个琥珀小点），
  右端**一个**「去记账」。几条共用一个链接：去处是同一页，一条一个就是一列一模一样的按钮。
  一模一样的句子只写一次、后面注明「（这样的记录有 2 笔）」——句子里已经有票、日期和股数，还一模一样就是
  两笔不同的记录碰巧长得一样（见 §6 第 5 条）。
- **持仓不在信号池**：挪到「当前持仓」标签页里、表格上面。它说的是持仓，不影响这一页的任何数字；
  自己拿主意买的票不在池子里是常态，页顶天天亮一条等于没有（同侧栏那条安全警告的道理）。
  明面上一句会变的话，「信号池是什么、要不要管」在后面的圆点里，右端一个「去信号池」。
- 这种"话 + 右端链接"的行用**按比例的两栏**（4:1，竖直居中），链接的字不超过四个。不能用靠右的横向容器：
  那种容器里文字元素按自己的内容要宽度，一句话长到要折行就独占整行、把链接挤到下一行（真机上看到的）。
- 那一行里的帮助圆点，提示框**锚在这一行的左缘、出在它下面**，不锚在圆点上：圆点跟在句子末尾，句子多长它就在
  多靠右的地方，照别处那样向右展开会伸出视口（§6 第 3 条）。
- 顺手修的一处：只看**手里真有的**（股数 > 0）。pnl 为了挂标记会在持仓里留一行 0 股的空壳，
  原先它不在池子里也会被提醒"不会盯它的卖出"——手里一股都没有，没有什么卖出可盯。
- 同一页的两个圆点里原先也写着「吃掉两个买入批次」「配对关系」「未配对的股数」「上面会有告警」
  （`TABLE_HINTS["closings"]`、`JOURNAL_PNL_HINT`），一并改成人话（§6 第 4 条）。

### 2.4 没做的

- **没有在这一页上加「一键加入信号池」**：加入要先知道这只票在不在可选范围里（主板、非 ST、上市满 400 天），
  那份清单可能要联网拉两到四分钟；这一页是只读的，不该因为一行提醒去写配置。链接到「信号池」页。
- **没有做「去记账」时把表单预填好**（代码、方向）：值得做，但它要改「记账」页的预填提示（现在那句话是给
  "从信号页过来"写的），是另一件事。句子里已经写明要补什么、日期怎么填。

## 3. 仪表盘：两张图各占一整行

> 同日稍后，持仓占比不再是 plotly 条形图：改成了「占比条 / 环形图」二选一的页面内 HTML，
> 见 `2026-11-18-weights-forms-design.md`。本节关于"各占一整行"的结论不变；§4 表里前三行说的那张
> 占比图（按字数留边距、类目轴）已随之删除，`_bar_margins` 只剩「来源对比」在用。

原先固定两栏（曲线 | 占比）。还没有已平仓的交易时左栏只有一句话——1440 宽下量出来是 482 × 340 的一栏里一行字。

| 状态 | 之前 | 现在 |
|---|---|---|
| 有持仓、没有已平仓的交易（用户现在的状态） | 左半边一句话 + 三百多像素的空，右半边占比图 | 占比图独占一行（高度只按行数给），下面一句「还没有已平仓的交易——有了之后这里会多出一条累计盈亏曲线。」 |
| 两样都有 | 并排 | **曲线一行、占比一行**（曲线在上：历史；占比在下：紧挨着持仓表，说的都是眼下手里有什么） |
| 全部卖光 | 左半边曲线，右半边一句「当前没有持仓，暂无占比可画。」 | 曲线独占一行；那句话删了——紧挨着的「当前持仓」标签页里已经写着没有持仓 |
| 空账本 | 两句并排 | 只剩缺曲线那一句 |

**为什么不并排**（初稿是"两张都有才并排"，§6 第 2 条）：占比图的类目标签加条外标注要两百多像素的**固定**边距
（§4 第一行，标注因此不会被裁）。1024 宽、侧边栏展开时对半分的一栏只有 274px，留给条的地方只剩十几像素；
持仓一多它还比 340px 的曲线高，曲线下面又是一块空。各占一行，这两件事都没有了。

缺曲线那句话从「还没有平仓记录——第一笔卖出后这里会出现…」改成说「已平仓的交易」：用户的账本卖过一笔，
只是找不到买入，原句对着它是一句假话。

## 4. 顺带修的几处图表毛病（都是在真机上看状态时撞见的，或审查指出的）

| 毛病 | 原因 | 修法 |
|---|---|---|
| 占比图最长那根条的标注被裁（用户截图里只剩前面的百分比、后面的金额看不见，量出来有 67px 画在图外） | 条外标注画在绘图区之外，右边距写死 40px；最长的条一定顶到绘图区右端 | 左右边距按字数留（`charts._bar_margins` / `_text_px`：等宽 12px，汉字一个字宽、其余 0.6 个）；估算与浏览器里量的几段字差不到 1px。「来源对比」那张图同一个毛病，一并用上 |
| 类目标签顶着图的左边缘 | plotly 自动撑开的左边距正好等于标签宽 | 左边距多留 14px |
| 持仓里有一只票**没有名称**时，占比图纵轴变成数值轴（刻度 `0.999999M`，其余的条全部消失） | 标签只剩六位代码，plotly 把整条轴猜成数值 | 纵轴钉成类目轴 |
| 曲线只有一个点时横轴刻度是 `23:59:59.9995`（用户按提示补记那笔买入之后正好是这个状态） | 自动范围零宽 | 点挤在两周以内时向两边各让出一些、凑满两周，两边至少各让一天（用时间戳算：拿日期加减会把半天丢掉） |
| 曲线的日期刻度是英文月份缩写；初稿改成 `2026-09-08` 又太长，图一窄整排斜过来 | 一个刻度 72px | 按刻度疏密分三档（`tickformatstops`）：`09-08`（年份另起一行、只在变的地方写）/ `2026-09` / `2026` |
| 「来源对比」图里亏损那一行的标注压在左边的类目名上，两行字叠成一团 | 亏损的条向左伸，条外标注跟着画到条的左边 | 亏损的行条上不写字，标注作为注记锚在零线右侧（那一行零线右边是空的） |

## 5. 验收

### 5.1 真机（Chrome，`/tmp` 里两份副本：一份是用户账本的拷贝，一份换着账本看状态）

- 1440 宽：三处改动都在；页名与「不在信号池」两个圆点悬停能出、内容完整。
- 1024 × 768、侧边栏展开，**用户账本的原样**：提示折成三行、「去记账」「去信号池」各一行不折；占比图最长的
  标注右缘离图边 28px；没有横向滚动条。
- 1024 × 768、侧边栏展开，**补记那笔买入之后**（两张图都有；初稿在这个状态下是坏的，当时只验了上一条）：
  曲线与占比各占一行，三根条宽 291 / 186 / 147px（并排时量出来是 15 / 10 / 8px），日期刻度水平排、
  年份只在第一个刻度下面；悬停「不在信号池」的圆点，提示框在 x = 395–747（改之前 801–1153，伸出视口 129px），
  页面不出横向滚动条。
- **照提示走了一遍**：在副本的「记账」页补记那笔买入（日期早于那笔卖出）→ 回到这一页，提示消失，
  已实现总收益有数了（与手算的"卖出净得 − 买入成本"一分不差），持仓表里那行 0 股的空壳也没了。
- 其余状态各看了一遍：多条提示摞在一起（五条 + 一个链接）、三只票不在池子里（其中一只没有名称）、
  两只无市价的持仓（标注带「（按成本）」）、全部卖光、空账本、有亏损来源的「来源对比」。
- 真实的 `journal/trades.csv` 全程没动（副本里那份与它逐字节相同；补记是在另一份副本里做的）。

### 5.2 测试

全量 2734 过（基线 2657），1 跳过。原有四条钉着旧写法的改成钉新行为；新增的钉：句子点名哪只票哪一天、
不出现内部的词、三种卖超各说各的、晚于卖出的买入确实配不上、股数怎么写；提示在数字之前、不是黄框、一个链接、
一模一样的句子注明几笔；提醒在持仓表上面、带圆点、不算 0 股的空壳、读不到配置时不出；两张图各占一行、谁都不在
半幅宽的栏里；整页（含圆点）不出现用户问过的那几个词；图表边距放得下最长的标注、纵轴是类目轴、
曲线的横轴让多少、刻度怎么写、亏损行的注记；提示框锚在行上。

### 5.3 变异自查

在工作区的拷贝里逐处改坏代码、看对应的测试红不红。第一轮（审查之前）33 处全部抓到；按审查修完之后的代码
重做一轮：**58 处，58 处被抓到**（图表 14 处、句子 12 处、页面 21 处、主题 4 处、文案 7 处）。
比第一轮多出来的都是冲着审查那几条去的：卖完了的又说成没有买入记录、记过买入却不认账、不提送股转增、
那时手里剩多少说成买入记了多少、股数用科学计数法；一模一样的句子不说几笔 / 写两遍 / 只有一笔的也带上几笔；
两张图又并排、占比图排到曲线上面；让出的半天被日期丢掉、两边不保证至少让一天、刻度又写成一整串年月日、
不赚不亏的那一行没有字；提示框又锚回圆点上、不限宽；两个圆点里又是批次与配对。

## 6. 独立审查（2026-11-18，一个不带作者结论的审查子代理）

它拿到的是代码、用户的三条原话和全站的规矩，没有拿到作者的结论；自己开标签页看了 12 份账本、三种宽度。
结论：没有严重问题（算盈亏的数与先进先出逻辑没被动到），五处该修、五处小问题。
