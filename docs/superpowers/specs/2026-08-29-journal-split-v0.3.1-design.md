# 交易日志拆分与持仓仪表盘 v0.3.1 设计文档

- 日期：2026-08-29
- 状态：待实施（用户诉求：日志页内容太多排版拥挤，拆成子页面；持仓盈亏页加仪表盘，可自由发挥）
- 前置：v0.3.0（1379 项离线测试全绿）

## 1. 页面结构：一页拆两页，侧栏成组

现「交易日志」一页塞了五块（录入/历史表/持仓/盈亏/导出），拆为：

| 子页 | 内容 | 对应用户诉求 |
|---|---|---|
| **记账** | 录入表单 + 历史日志表（筛选/编辑/删除）+ 导出 | "记录"与"历史展示筛选"同页 |
| **持仓与盈亏** | 仪表盘（指标块+两图）+ 三个 tab（持仓 / 平仓明细 / 来源对比） | "持仓"与"盈亏"同页 + 仪表盘 |

侧栏用 `st.navigation` 的**分组形态**（1.61.1 实测支持 `Mapping[str, Sequence[Page]]`）：

```
使用说明 / 任务控制台 / 今日信号        ← 主组
交易日志 ▸ 记账
         ▸ 持仓与盈亏
信号池 / 回测报告 / 个股K线            ← 研究组
```

实施时先验证空字符串键 `""` 是否渲染为无标题组；不行则给三组都起名（如「工作台」「交易日志」「研究」）。「今日信号」页「记账」按钮的 `st.switch_page` 目标改指「记账」子页。

页内减拥挤：录入表单占一个卡片区，历史表全宽；持仓页三张表收进 `st.tabs`（不再纵向全部铺开）。

## 2. 仪表盘（自由发挥部分，按 dataviz 规范落地）

### 2.1 指标块（复用既有 .qd-metric，2×3）

总已实现（含分红）/ 当前持仓市值 / 浮动盈亏 / 总盈亏（已实现+浮动）/ 胜率 / 盈亏比。
浮动与市值依赖本地行情缓存：**缺价标的如实显示"—"并在旁注明"N 只无市价未计入"**，不填 0。

### 2.2 累计已实现盈亏曲线

- **阶梯线（plotly `line_shape="hv"`）**，不是平滑曲线——已实现盈亏在**平仓时点跳变**，
  平滑连线是在编造两笔平仓之间的过程。数据点 = 每笔平仓/分红后的累计值。
- 单序列琥珀、零轴基线（浅灰参考线）、无图例（单序列，标题即名）、plotly 自带 hover。
- 空态（尚无平仓记录）：不画空图，显示引导文案"还没有平仓记录——第一笔卖出后这里会出现你的已实现盈亏曲线"。

### 2.3 持仓占比

- **横向条形图**按市值降序，不做饼图：持仓通常 3~10 只，条形对比精度远高于扇形角度，
  且排序后一眼看出集中度。
- **单一琥珀色** + 右端直接标注百分比与市值。
- 无市价的标的按持仓成本计入并在条上打「按成本」标——诚实优于漏项（漏了会让占比虚高）。

### 2.4 来源对比（信号 vs 自主）

横向分组条：类目（ma_cross / donchian / discretionary…）由**轴标签**承载身份，
条一律单色琥珀，右端直接标注已实现盈亏与胜率。不用颜色区分来源——见 §2.5。

### 2.5 配色决定（校验驱动，如实记录）

按 dataviz 规范用校验脚本实测（暗色面）：**琥珀 #C8963E + 灰 #8C8778 作为类别对
过不了正常视力可辨阈值**（ΔE 12.7 < 15，色盲模式 11.1 也仅勉强），灰的彩度低到"读作灰"。

**决定：新仪表盘零类别配色。** 全部图表单色系（琥珀）+ 方向色（红涨绿跌，属状态色不
在类别校验范围）+ 位置/轴标签/直接标注承载身份。这从构造上规避了辨识问题，也贴合
"金融电报"的克制审美——颜色只给方向与强调，不给装饰。

既有回测净值图的三线（琥珀实线/灰点线/米白虚线）**维持现状**，豁免理由记录在案：
三线有线型二次编码 + 图例 + 语义上是"主线与两条退后的基准"的层级关系而非平级类别，
灰与米白的低彩度正是"退后"的刻意表达。

### 2.6 明确不做："账户收益率 % 曲线"

日志不记录账户本金与出入金，任何收益率分母都是编造。曲线用**累计已实现盈亏（元）**——
它可以从日志精确推导。页面注明这一取舍；将来若加"本金/出入金"记录类型再升级成真收益率。

## 3. 分层

```
src/quant/journal/analytics.py     # 纯函数：cumulative_realized(trades) -> [date, cum]
                                   #        （平仓+分红合并按日累计，阶梯数据点）
                                   #        position_weights(positions, prices) -> rows
                                   #        （市值或成本 fallback + by_cost 标记）
src/quant/report/charts.py         # 新增 journal_cum_pnl_chart / position_weights_chart /
                                   # source_compare_chart（走 palette，暗色与既有一致）
app/pages_journal_entry.py         # 记账页（原录入+历史+导出，逻辑不改只挪）
app/pages_journal_report.py        # 持仓与盈亏页（仪表盘 + tabs）
app/journal_ui.py                  # 共享件保留
```

原 `app/pages_journal.py` 删除；页面函数**逻辑不改只挪**，把重构风险压到最小。

## 4. 测试

- **analytics 手算单测**：多笔平仓+分红交错的累计序列（含同日多笔合并）、
  空日志、只有分红；position_weights 的成本 fallback 与标记、全部无价、权重和=1
- charts 三个新图 smoke（含空数据不崩）
- nav：分组结构断言（组名、组内顺序、默认页仍是使用说明）；switch_page 目标钉住指向记账页
- guide：PAGE_INTRO 两个新页替换原一页；TABLE_HINTS 不变（表没变只是挪位与进 tab）
- AppTest：两个子页 × 空日志/有数据/有一致性告警 三态
- 回归：1379 项基线

## 5. 不做

- 不做账户收益率 %（§2.6）
- 不做时间范围切换器（YAGNI，数据量小，全期展示即可）
- 不改 journal/trades.csv 的任何字段与语义
- 既有回测图表配色不动
