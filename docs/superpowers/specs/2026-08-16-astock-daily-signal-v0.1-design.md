# A 股日线信号系统 v0.1 设计文档

- 日期：2026-08-16
- 状态：已通过文档评审与领域评审（v2，含评审修订）
- 作者：杨明阳 & Claude

## 1. 背景与目标

用户是量化交易初学者，希望构建一个基于技术分析的入场时机提示系统。v0.1 的首要目标是**学习与跑通**，而非产出盈利策略：搭建一条完整、正确、可扩展的研究流水线——

```
拉数据 → 算指标 → 策略出信号 → 历史回测 → 评估报告 → 每日信号提示
```

市场与周期：**A 股，日线**。后续版本再扩展港股/美股。

## 2. 范围

**v0.1 做：**

- 数据层：A 股日线行情获取与本地缓存（baostock 首选 / akshare 备选）
- 指标层：MA、N 日最高/最低、ATR 等基础指标
- 策略层：双均线、唐奇安通道突破两个内置策略
- 回测引擎：自研轻量引擎（含 A 股交易规则与成本模型）
- 报告层：绩效指标、基准对比、净值曲线、K 线买卖点标注图
- UI 层：Streamlit 本地面板（回测报告 / 个股 K 线 / 今日信号 三页面）
- 每日信号脚本：收盘后运行，输出当日触发信号清单

**v0.1 不做（明确排除）：**

- 实盘/模拟盘自动下单
- 分钟级、盘中实时信号
- 港股/美股（架构预留，不实现）
- 定时任务与飞书推送（v0.2）
- 参数优化/扫描（v0.2+）
- 常驻后台进程——所有组件均按需运行

```
│   │   ├── baostock_provider.py
│   │   ├── akshare_provider.py

│   ├── indicators/          # 指标层：纯函数库

│   │   ├── costs.py         #   成本模型（含分段印花税）
│   │   └── portfolio.py     #   账本（现金/持仓/净值）
│   ├── report/              # 报告层：绩效指标 + plotly 图表
│   └── signal/              # 每日信号扫描
├── scripts/

│   └── run_daily_signal.py  # 入口：每日信号
├── app/
│   └── dashboard.py         # Streamlit 面板入口
├── data/cache/              # 行情缓存（gitignore）
├── output/                  # 回测报告、信号清单（gitignore）
└── tests/                   # 单元测试
```

**分层原则**：策略层只依赖行情 DataFrame，不知道数据来源；回测引擎只消费策略信号，不知道策略逻辑；UI 层只读展示，不含业务逻辑。任何一层可独立替换（如未来数据层换富途 OpenAPI、回测层换 backtrader）。

**数据流**：`DataProvider → 缓存 → 策略(含指标计算) → 信号序列 → 回测引擎 → 账本/交易记录 → 报告/UI`；每日信号复用同一条链路，只是不进回测引擎，直接取最新一日信号。

## 4. 关键设计决策

| # | 决策 | 方案 | 理由 |
|---|------|------|------|
| 1 | 价格口径 | **信号计算用后复权价**（原始价 × 复权因子，保证指标跨除权日连续）；**撮合、约束检查、成本计算用原始未复权价**（真实价位）；持仓跨除权除息日按复权因子比率调整股数（等效分红再投资） | 前复权价随每次除权改写历史，引入未来信息；而整手、最低佣金、涨跌停等真实约束只有在原始价上才有意义 |
| 2 | 成交时点 | T 日收盘后计算信号，**T+1 日开盘价**成交 | 杜绝"当日收盘信号当日成交"的未来函数 |
| 3 | 涨跌停约束 | 买单遇涨停取消顺延、卖单遇跌停同理；判定用原始价：开盘价距昨收 ≥9.5% 或当日 high == low（一字板） | A 股特色；不处理会系统性虚高收益 |
| 4 | T+1 制度 | 当日买入的仓位当日不可卖出 | 如实模拟 A 股规则 |
| 5 | 成本模型 | 佣金 万 2.5（单笔最低 5 元，双边）+ 印花税（仅卖出，**分段**：2023-08-28 前 0.1%，之后 0.05%）+ 滑点 0.1%（涵盖过户费等杂费） | 不扣成本的回测是幻觉；印花税历史上有调整，用现行税率回溯会低估历史成本一半 |
| 6 | 停牌 | 数据层在指标计算前**过滤停牌行**（trade_status=0）；停牌日不交易、信号顺延，持仓按最近可得收盘价估值 | 停牌行的 0 成交量会污染均量/滚动窗口指标 |
| 7 | ST 股 | 股票池默认剔除 ST/*ST | 规避特殊涨跌幅（5%）与退市风险，简化 v0.1 |
| 8 | 股票池板块 | v0.1 限定**主板**股票（涨跌幅 10%） | 避免创业板/科创板 20% 涨跌幅的分支逻辑 |
| 9 | 数据缓存 | parquet 本地缓存，增量更新 | 减少对免费接口的请求；提高回测速度 |
| 10 | 信号语义 | 策略输出**目标仓位状态**（1=应持有，0=应空仓），引擎将状态变化翻译为次日订单 | 比事件式（买/卖点）更不易漏信号、易于测试 |
| 11 | 量能口径 | 量能类条件统一用**成交额（amount）**而非成交股数 | 复权只调价格不调股数，送股/转增会使跨除权日的"股数均量"失真；成交金额不受股本变动影响 |

## 5. 数据层

### DataProvider 接口

```python
class DataProvider(ABC):
    def get_daily_bars(symbol, start, end) -> DataFrame
    #   列（原始未复权口径）：date, open, high, low, close, volume, amount,
    #        adj_factor(后复权因子), trade_status(是否正常交易), is_st
    #   数据层基于 adj_factor 派生后复权列：adj_open, adj_high, adj_low, adj_close
    def get_index_daily(index_code, start, end) -> DataFrame   # 基准指数
    def get_trade_calendar(start, end) -> list[date]
```

- **首选 baostock**：免费、无需 token，日线数据含复权因子、`tradestatus`（停牌标记）与 `isST` 字段，并提供指数行情与交易日历。
- **备选 akshare**：接口先就绪（抽象层已隔离），实现可推迟到 baostock 实际失效时再补，以压缩 M1 工作量。
- 缓存策略：每标的一个 parquet 文件；运行时检查本地最新日期，只增量拉取缺失部分；提供 `--refresh` 强制全量刷新。
- 停牌行处理：`trade_status=0` 的行在进入指标计算前过滤掉（见决策 6），估值时沿用最近可得收盘价。
- 数据质量校验（作用于**原始价**）：日期重复、OHLC 逻辑（high ≥ low 等）、异常跳变——单日 |涨跌| > 11%（主板池阈值）且当日复权因子未变化（非除权除息日）则告警写入日志。

## 6. 指标层

全部为纯函数：输入 DataFrame/Series，输出 Series，无状态、无副作用，便于单测。

v0.1 提供：`ma(series, n)`、`rolling_high(series, n)`、`rolling_low(series, n)`、`atr(df, n)`。

窗口约定：指标函数本身为"含当日"的标准滚动窗口；需要"不含当日"（如突破类比较）时由**策略层先 shift(1) 再调用**，策略规则中必须写明。

## 7. 策略层

```python
class Strategy(ABC):
    name: str
    params: dict
    def generate_positions(df: DataFrame) -> Series  # 值 ∈ {0, 1}，索引=交易日
```

约定：`generate_positions` 只能使用**当日及以前**的数据（引擎会用错位测试验证无未来函数）；价格指标基于后复权列（adj_*）计算。

**内置策略 1：双均线（ma_cross）**
- 参数：fast=20，slow=60
- 规则：MA(fast) 上穿 MA(slow) → 目标仓位 1；下穿 → 目标仓位 0

**内置策略 2：唐奇安通道突破（donchian）**
- 参数：entry_n=20，exit_n=10，amount_n=20，amount_ratio=1.5
- 入场：当日收盘价 > **前 entry_n 日（不含当日，即先 shift(1) 再滚动）**最高收盘价，且当日成交额 > amount_ratio × 前 amount_n 日平均成交额 → 目标仓位 1
- 出场：当日收盘价 < 前 exit_n 日（不含当日）最低收盘价 → 目标仓位 0
- 注意：窗口若含当日，"收盘价 > N 日最高"永不成立（当日收盘价自身在窗口内），策略将输出死信号——测试须覆盖此回归

两个策略均为流水线验证品，不承诺盈利。

## 8. 回测引擎

**输入**：`{symbol: 日线 DataFrame（含原始价与 adj_* 列）}`、`{symbol: 目标仓位 Series}`、配置（本金、成本参数）。

**资金模型**：虚拟本金 500 万；股票池 N 只等权，每只资金上限 = **初始本金**/N（固定额度，不随权益浮动）；按 100 股整手、以原始价计算可买股数。
（本金取 500 万而非 100 万的原因：贵州茅台原始价 1 手即十余万元，本金过小会导致高价股静默无法建仓。）

**每日主循环**（按交易日历顺序）：

1. 读取各标的 T-1 日收盘时的目标仓位，与当前实际仓位比对，生成 T 日订单
2. 约束检查：停牌跳过；买单遇涨停（原始开盘价 ≥ 昨收 × 1.095，或当日 high == low 的一字上板）取消顺延；卖单遇跌停同理；卖单校验 T+1（持仓建立日期 < T）
3. 以 T 日**原始开盘价 ± 滑点**撮合，按分段税率计印花税、计佣金，更新账本
4. 除权除息日处理：持仓股数 × (当日复权因子 / 前日复权因子)，现金不变——等效于分红再投资；调整后股数可为非整数（已知近似，如实记录）
5. 以 T 日原始收盘价对全部持仓估值（停牌标的沿用最近可得收盘价），记录当日净值

**输出**：净值曲线（日频 Series）、交易明细（entry/exit 时间价格、盈亏、成本）、每日持仓快照。

## 9. 报告层

**绩效指标**：总收益率、年化收益率、最大回撤、夏普比率（年化，rf=0，注明中国无风险利率约 1.5–2%，此为简化口径）、胜率、盈亏比、交易次数、平均持仓天数。

**基准对比**：同期沪深 300 指数收益、股票池等权买入持有（按分红再投资口径，与策略同权）收益，与策略并列展示。注明：沪深 300 为价格指数不含分红，相对策略净值有每年约 2–3% 的天然劣势；等权买入持有基准无此偏差，为主要参照。

**图表（plotly，输出 HTML 文件，UI 层复用）**：
- 净值曲线（策略 vs 两条基准）+ 回撤曲线
- 单标的 K 线图 + 买卖点标注（▲买入 ▼卖出）——策略调试的主要工具

**文件输出**：`output/<策略>_<时间戳>/` 下的 report.html、trades.csv、equity.csv。

## 10. UI 层（Streamlit）

按需启动：`streamlit run app/dashboard.py`，本地浏览器访问；不常驻。

三个页面：
1. **回测报告**：选择策略与已有回测结果，展示绩效指标表、净值/回撤曲线、交易明细表
2. **个股 K 线**：选择标的与策略，展示交互式 K 线 + 指标线 + 买卖点标注
3. **今日信号**：展示最近一次 `run_daily_signal.py` 的信号清单及历史信号记录

约束：v0.1 的 UI 为**纯只读**——仅读取 output/ 与缓存数据做展示，不提供触发回测/信号的按钮（页面上提示对应命令行用法）。触发能力留给 v0.2 评估。

## 11. 每日信号

`scripts/run_daily_signal.py` 流程：增量更新股票池数据 → 校验当日数据已到位（非交易日或数据未更新则明确提示退出）→ 各策略对各标的计算最新目标仓位 → 与上一交易日比对，输出**新增买入/卖出信号**清单（终端表格 + `output/signals/YYYY-MM-DD.csv`）。

运行方式：v0.1 收盘后手动运行；v0.2 接入系统定时任务 + 飞书推送（定时不早于 **18:30**——baostock 日线数据约在交易日 17:30 后才更新，过早会空跑）。

## 13. 测试策略

回测引擎的正确性高于一切——**引擎不可信则一切结论不可信**。

- **引擎测试**：用手工构造的小数据集（3~5 个交易日、答案可手算）逐项验证：次日开盘成交、佣金/滑点计算、最低佣金 5 元、**分段印花税（跨 2023-08-28 各取一例）**、涨停买单顺延、跌停卖单顺延、一字板判定、停牌跳过、T+1 卖出限制、整手取整、**除权除息日股数按因子调整且净值连续**。
- **指标测试**：纯函数对照手算值。
- **策略测试**：构造已知走势数据，验证信号位置；**唐奇安死信号回归测试**（构造持续创新高序列，断言信号非全 0）；错位测试验证无未来函数（把未来数据抹掉，历史信号不得改变）。
- **数据层测试**：缓存增量更新逻辑、停牌行过滤、数据校验规则（用本地样本数据，不依赖网络）。

## 15. 风险与备注

- **Python 3.14 兼容性**：当前 venv 为 Python 3.14.7，baostock 等老库可能不支持。M1 第一步先验证依赖安装；不行则降级新建 Python 3.12 venv（对项目无其他影响）。
- **免费数据源接口变动**：baostock/akshare 接口可能变化，数据层已隔离，必要时切换实现。
- **涨跌停判定为近似**：开盘价阈值 + 一字板判定仍无法完全复现盘口真实可成交性；对日线级学习项目可接受，如实标注。
- **除权日股数调整为近似**：分红再投资假设产生非整数持仓股数，与真实账户行为（现金分红入账）略有差异；对学习项目可接受，如实标注。
- **本设计中所有策略仅用于学习流水线，不构成投资建议。**
