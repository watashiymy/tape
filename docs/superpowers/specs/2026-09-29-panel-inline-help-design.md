# 面板就地帮助改版：去掉弹出框，改成紧贴对象的小圆圈「?」（2026-09-29）

分支：`feat/v0.6-market-overview`（随市场概览首页一起合并）。

## 0. 起因与用户决定

用户截图圈出首页三个「? ⌄」按钮：「很奇怪，不知道是什么东西」。实测原因三条：

1. **长得像下拉框。** 它们是 `st.popover("?")`。Streamlit 1.61.1 给每个弹出框强制加下拉箭头
   （只有标签恰为 `:material/menu:` 等三个图标时例外），所以「?」看起来是选择框。
2. **不挨着被解释的东西。** 温度计那个在 2×2 卡片下方；趋势宽度那个在四卡下方、贴着第一张；
   按钮区那个在按钮**左边**的 1/7 列里，与按钮之间空出约 80 px。后两个在同一竖线上上下相距 56 px。
3. **打开要自己对号。** 温度计弹出框一次列四段，「涨停」「跌停」两段不写自己说的是哪个数。

同一页上成交额那行和分布图说明末尾，已经有 `st.caption(help=)` 的原生小圆圈「?」，悬停即出说明——
这是用户认得的样子。对照页（三方案并排）实测后，**用户选定**：

- **方案甲**：每张卡片标签后紧跟一个小圆圈「?」，悬停只解释这一个数；首页按钮去掉旁边的「?」，
  说明改为悬停按钮本身出现；三个弹出框全部去掉。
- 同批顺手改：**任务控制台**三张任务卡片的「?」按同一样式改；**六张指数卡片**分时小图对齐；
  **「52 周新高 / 新低」**卡片小图与左边三张对齐。

否决的两案（留作记录，别再提）：区块标题旁放原生圆圈（`st.html` 默认铺满整行，圆圈被挤到行尾，又离标题很远）；
弹出框挪到标题行右侧（下拉箭头去不掉，仍像选择框）。

## 1. 帮助圆点（新构件）

### 1.1 外观与行为

- 一个直径约 0.95rem 的描边圆圈，里面一个「?」，颜色取 `--qd-muted`；悬停或获得焦点时圆圈与字变 `--qd-text`。
  尺寸与观感向原生 `help=` 图标看齐（同一页两种圆圈并存，不能一大一小、一实一空）。
- 悬停或 **Tab 键选中**（`tabindex="0"`）时，在圆圈下方出现提示框；移开或失焦即消失。**无动画**
  （`tests/test_theme.py` 禁止 `transition` / `animation` / `@keyframes`）。
- 提示框：底色 `SURFACE`、1px `HAIRLINE` 描边、文字 `--qd-text`、约 0.8rem、行高 1.5、圆角、投影；
  宽度固定一档（首页卡片短句用窄档约 15rem，任务说明用宽档约 22rem），`white-space: normal`。
- **对齐**：默认从圆圈左侧向右展开；调用方可指定向左展开（`end`），用于一行里最右边的卡片，
  使提示框不越出视口右缘。首页：温度计每行第二张、趋势宽度第四张用 `end`。
- 颜色**只取色板**：新增 `--qd-surface` 进 `:root`（值为 `SURFACE`），投影用 `rgba(0,0,0,…)`
  这种非十六进制写法（`test_every_hex_in_css_comes_from_the_palette` 只管十六进制）。所有选择器以 `.qd-` 开头。
- `aria-label` 写「说明」（走 `guide`），读屏软件能读到提示框里的文字（它就在 DOM 里，只是隐藏）。

### 1.2 内容格式（极简 Markdown）

提示框文字**先整体 HTML 转义，再**只认三种写法，其余原样显示：

| 写法 | 渲染 |
|---|---|
| `**加粗**` | `<b>` |
| 空行分段 | 段落 |
| 行首 `- ` 的列表项；紧随其后、以空格缩进的行是该项的续行 | 列表 |

段内单个换行当作空格（与 Markdown 一致；`JOB_HELP` 的列表项靠续行缩进写长句）。这三种正好覆盖现有
全部帮助文案：`HOME_HELP` 是纯文字；四条 `JOB_HELP` 只用了加粗、带续行的列表与空行（2026-09-29 逐条核对，
无代码、链接、标题、编号列表、单星号）。**不做通用 Markdown**：要新写法时再扩，并同步本表与测试。

### 1.3 放在哪一层

- 纯函数 `theme.help_dot(text, *, align="start", wide=False) -> str` 生成圆点 HTML；
  极简 Markdown 转换是它的私有辅助函数，单独单测（转义在前、XSS 用例、续行、分段、加粗不跨段）。
- `theme.stat_card(..., help="", help_align="start")`：`help` 非空时圆点紧跟在标签文字后，**在
  `qd-card-label` 那个 div 里**。`label` 为空（纯图卡）时忽略 `help`。
- `theme.section(title, pill_html="", *, help="", help_wide=False)`：圆点紧跟标题文字、在 pill 之前。
- 不用 `<svg>`（`st.html` 会删掉，首页测试扫所有 `st.html` 体）。不碰 Streamlit 内部类名与 `data-testid`。
- 文案一律来自 `guide`，页面不写字面量（现行规则不变）。

## 2. 各页挂点

### 2.1 首页（`app/pages_home.py`）

- **涨停温度计**：四张卡片各挂自己的一句：`HOME_HELP["limit_up" | "limit_down" | "zb_rate" | "max_lbc"]`。
  删掉卡片下方的 `st.popover("?")`。
- **趋势宽度**：三张「站上 N 日线」各挂 `HOME_HELP["above_ma"]`，**文案改成带 `{n}` 的模板**
  （「收盘价高于自己近 {n} 日均价的股票占比……」），页面按 20/60/200 填；「52 周新高 / 新低」挂
  `HOME_HELP["high_low"]`。分母为 0、显示「—」的卡片也挂（那时最需要知道这个数是什么）。删掉四卡下方的弹出框。
- **按钮区**：去掉 `st.columns([1, 6])` 与其中的弹出框；「开始准备」「更新收盘数据」按钮 `help=JOB_HELP["market_breadth"]`
  （原生按钮提示，支持加粗与列表，实测可用）。运行中、别的任务在跑、未到就绪时刻、已是最新这几态本来就没有这个按钮，
  也就没有这段说明——这与现在一致（弹出框也只在有按钮时出现）。
- 成交额行、分布图说明行的原生 `help=` 不动。

### 2.2 任务控制台（`app/pages_console.py::_card_head`）

- 去掉 `st.columns([5, 1])` 与弹出框，改为 `theme.section(job.label, pill_html, help=JOB_HELP[job.name], help_wide=True)`：
  圆点紧跟卡片标题文字。**不挂在按钮上**：状态文件损坏的分支没有按钮，而 docstring 写明那正是最需要说明的时候。
- `_card_head` 的 docstring 改写（「右上角」→「紧跟标题」，保留「帮助必须与标题同一行」的理由）。
- 「人工步骤」那行已在 2026-09-14 改成链接自带 `help=`，不动。

## 3. 两处对齐

### 3.1 六张指数卡片

现状：1280 px 宽时卡片约 123 px，副文「−319.10 · −2.34%」在部分卡片折成两行，卡片高 107/128 px 交替，
分时小图高低不齐。改法：**涨跌额与涨跌幅固定分两行**（`stat_card` 的 `sub` 接受多段，每段一行、同色），
去掉中间的「 · 」。六张卡片结构一致，任何宽度下小图都在同一水平线上。

### 3.2 「52 周新高 / 新低」卡片

现状：三张「站上 N 日线」有副文「2070/5004」，这张没有，小图高出约 20 px。改法：补一行副文
`guide.HOME_HL_TOTAL = "共 {n} 只"`，`n` 取指标表的 `n_hl`（参与新高新低统计的股票数），与左边三张的分母同义。
分母为 0、显示「—」时不出副文（与左边三张分母为 0 时一致）。

## 5. 测试

- `tests/test_theme.py`：`help_dot` 转义（含 `" onmouseover=` 与 `<script>`）、三种写法、续行、单换行变空格、
  `align="end"` 与 `wide` 出对应类、无 `<svg`；`stat_card(help=)` 圆点在标签 div 内、空标签时不出圆点、
  无 `help` 时输出与现在逐字相同；`section(help=)` 圆点在标题后、pill 前、标题仍被 `>` 与 `<` 夹住；
  新 CSS 类都有规则；无动画、无新十六进制。
- `tests/test_dashboard_home.py`：首页 `at.get("popover") == []`；温度计与趋势宽度每张卡片 HTML 含**它自己**那句说明
  （且不含别张的）；「站上 60 日线」说明含「近 60 日」；按钮 `help == JOB_HELP["market_breadth"]`；
  六张指数卡片各有两行副文、不含「 · 」；52 周卡片有「共 N 只」。`_card` 测试助手改为按标签前缀匹配
  （标签 div 里多了圆点）。原「`HOME_HELP["above_ma"]` 在 `at.markdown` 里」那条改为在卡片 HTML 里。
- `tests/test_dashboard_guide.py`：控制台 `at.get("popover") == []`；三张卡片的标题 HTML 各含自己 `JOB_HELP`
  的首行文字；「帮助与标题同一行」改为断言圆点在同一个 `qd-section` 里。回测报告等页无弹出框的断言保留。
- 变异自查：删掉任一张卡片的 `help=`、`end` 对齐反置、转义顺序颠倒、指数卡片副文合回一行——各至少一条测试红。

## 6. 验收（真浏览器）

- 1280 px 与 1024 px 两种宽度，逐个悬停首页 8 个圆点与 2 个按钮、控制台 3 个圆点：提示框完整、不越出视口、
  文字是对应的那句；Tab 键能依次选中圆点并显示提示框。
- 用脚本读六张指数卡片小图、四张趋势卡片小图的 `getBoundingClientRect().top`：各组内相差不超过 1 px。
- 首页与控制台都没有「⌄」下拉箭头。

## 7. 不做

- 不改提示框以外的交互（按钮、进度、刷新节奏都不动）。
- 不做通用 Markdown、不做点击固定的提示框：面板只在本机桌面浏览器用（默认绑 127.0.0.1），触屏不在考虑内。
- 不动成交额行、分布图说明、参数控件、链接上已有的原生 `help=`。
